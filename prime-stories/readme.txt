Prime Stories by Webiitor adds a professional Instagram-style story system to WordPress with Elementor support, shortcode placement, scheduling, smart display rules, and basic analytics.

== Description ==

Prime Stories is a commercial-grade foundation for publishing modern image and video stories on WordPress websites.

Built by Webiitor, the plugin helps site owners create story groups, schedule visibility, place stories with Elementor or shortcodes, control automatic display rules, and track basic engagement events from a clean admin experience.

Main capabilities:

* Instagram-style image and video stories
* Elementor widget integration
* Shortcode support
* Story groups and scheduling
* Smart display rules by page, device, and audience
* Mobile-first fullscreen viewer
* CTA buttons and basic analytics
* Built-in diagnostics logs for faster troubleshooting
* Responsive and RTL-friendly frontend

Company:

* Webiitor
* https://webiitor.ir/

== Installation ==

1. Upload the `prime-stories.zip` file through `Plugins > Add New > Upload Plugin`.
2. Activate `Prime Stories`.
3. Create story groups from the `Stories` menu.
4. Add stories, configure media and schedule settings, then place them with Elementor, shortcode, or display rules.

== Frequently Asked Questions ==

= Does Prime Stories require Elementor? =

No. Elementor is optional. The plugin works with shortcodes and automatic display rules even when Elementor is not installed.

= Does Prime Stories require WooCommerce? =

No. WooCommerce-related display rules fail safely when WooCommerce is not active.

= How can I place stories manually? =

Use the shortcode:

`[prime_stories group="homepage" layout="circle" limit="10" autoplay="true"]`
