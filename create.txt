You are a senior WordPress plugin developer and full-stack engineer.

I want you to build a professional WordPress plugin called **Prime Stories**.

The plugin must add a complete Instagram-style Story system to WordPress websites, with full admin management, Elementor compatibility, shortcode support, display rules, responsive frontend viewer, scheduling, and basic analytics.

The website is built with Elementor, so Elementor integration is very important.

Your task is to implement the plugin with clean, scalable, secure, production-ready WordPress code.

---

# 1. Plugin Goal

Build a WordPress plugin that allows website admins to create, manage, group, schedule, and display stories anywhere on their WordPress website.

The plugin should support:

* Image stories
* Video stories
* Story groups
* Elementor widget
* Shortcode
* Display rules
* Fullscreen story viewer
* CTA button
* Scheduling
* Seen/unseen state
* Basic analytics
* RTL support
* Responsive mobile-first design
* Admin settings panel

The plugin should be built in a professional modular structure, not as a single messy file.

# 7. Security Requirements

Implement all WordPress security best practices:

* Use nonces for all meta box saves
* Verify user capabilities
* Sanitize all inputs
* Escape all outputs
* Use `esc_html`, `esc_attr`, `esc_url`, `wp_kses_post` where needed
* Do not trust any request data
* Do not expose private admin data on frontend
* Use prepared SQL queries for custom database operations
* Prevent direct file access using `defined('ABSPATH') || exit;`

* Story impressions
* Story opens
* Story completions
* CTA clicks

Create a custom database table on plugin activation:

```text
wp_prime_stories_analytics
```

Fields:

```text
id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
story_id BIGINT UNSIGNED NOT NULL
event_type VARCHAR(50) NOT NULL
user_id BIGINT UNSIGNED NULL
session_id VARCHAR(191) NULL
created_at DATETIME NOT NULL
```

Event types:

* impression
* open
* complete
* click

Use AJAX or REST API to record events.

```text
Stories > Analytics
```

* Total impressions
* Total opens
* Total completions
* Total clicks
* CTR
* Completion rate
* Top stories table

No need for advanced charts in version 1, but structure the code so charts can be added later.

Use WordPress database best practices.
